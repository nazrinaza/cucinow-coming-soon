# CuciNow — Coming Soon

Animated temporary landing page for **cucinow.co**.

- Single-file `index.html` (logo embedded base64, no external assets besides Google Fonts)
- Dark navy theme, periwinkle/gold palette sampled from the CuciNow logo
- Logo sheen sweep, floating logo, parallax tilt, ambient dust particles
- Respects `prefers-reduced-motion`
